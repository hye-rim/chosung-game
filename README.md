# 훈민정음

술자리 초성 게임을 브라우저로. 초성(예: `ㅅㅊ`)이 나오면 그 초성에 딱 맞는 단어를 입력하세요. — [작은 오락실](https://github.com/hye-rim/smallgame) 게임

## 모드

- **혼자 도전**: 맞힌 개수가 늘수록 덜 흔한 초성·세 글자가 나오고 제한 시간이 줄어요. 콤보·빠른 답·희귀 단어에 보너스. 패스 2번, 시간 초과 시 힌트 예시.
- **온라인 대결**: 2~6명이 방을 만들고(초대 링크 `?room=코드`) 차례대로 단어를 말해요. 차례마다 제한 시간이 있고(13초 → 단어가 쌓일수록 최대 6초까지 감소), 시간 초과·오답이 3번이면 탈락, 마지막까지 남으면 승리. 빠른 대전(2명 자동 매칭)도 있어요. 새로고침·잠깐 끊김은 자리를 지켜 줘요.

## 실행

```bash
npm install
npm start        # PORT 환경변수로 포트 지정 (기본 3005)
```

작은 오락실 로비에서는 서버 게임으로 함께 실행되며 `/chosung/` 아래로 연결돼요.

## 사전

`data/nouns.txt`(정답 판정용 2~3글자 명사), `data/common.txt`(자주 쓰는 명사: 문제 선정·예시용).
[han-dle/pd-korean-noun-list-for-wordles](https://github.com/han-dle/pd-korean-noun-list-for-wordles)(CC0)를 가공한 것으로,
원 출처는 표준국어대사전(2018)과 한국어 학습용 어휘(2019)예요. 자세한 내용은 `data/NOTICE.txt`.
